# 마을회계 프로그램

마을(리 단위) 공동체 회계 관리를 위한 오프라인 우선(offline-first) 웹 애플리케이션입니다. 별도의 서버나 데이터베이스 없이, 브라우저 안에서 모든 계산과 저장이 이루어집니다.

## 특징

- **설치 없이 브라우저에서 바로 사용**: 정적 HTML 한 장으로 동작하며, 별도 빌드 과정이 없습니다.
- **로컬 자동 저장**: 입력한 회계 자료는 이 브라우저의 `localStorage`에 자동 저장됩니다.
- **수동 백업/복원**: 설정 화면에서 JSON 파일로 자료를 내려받아 보관하거나, 다른 PC/브라우저로 불러올 수 있습니다.
- **비영리 목적 배포**: 마을회·주민자치회 등 비영리 단체가 자유롭게 가져다 쓸 수 있도록 공개했습니다.

## 실행 방법

### 온라인 (권장)

Vercel로 배포된 주소에 접속해 바로 사용하면 됩니다.

### 로컬 실행

`index.html` 파일을 더블클릭해서 열거나, 아래처럼 정적 서버로 띄워도 됩니다.

```bash
npx serve .
```

## 데이터는 어디에 저장되나요?

이 프로그램은 서버가 없습니다. 입력한 모든 자료는 **지금 사용 중인 브라우저(기기)에만** 저장됩니다.

- 같은 PC, 같은 브라우저로 다시 접속하면 마지막 작업 내용이 그대로 이어집니다.
- 브라우저 저장공간을 지우거나(캐시 삭제), 다른 PC·다른 브라우저로 접속하면 자료가 보이지 않습니다. 이럴 때를 대비해 **주기적으로 [설정] 화면에서 자료를 파일로 저장**해 두는 것을 권장합니다.
- 여러 사람이 같은 배포 주소에 접속해도 서로의 자료는 공유되지 않고, 각자의 브라우저에만 따로 저장됩니다(마을 전체가 자료를 공유하려면 백업 파일을 주고받아야 합니다).

## 배포 (Vercel)

이 저장소는 빌드 과정이 필요 없는 정적 사이트입니다. Vercel에서 "New Project → 이 GitHub 저장소 선택 → Deploy"만 누르면 별도 설정 없이 배포됩니다(Framework Preset: Other/정적 사이트로 자동 인식).

## PDF 첨부/인쇄 관련 안내

증빙 PDF 첨부, 파일 열기/인쇄 연동 기능은 **로컬 실행 파일(EXE) 버전에서만 동작**합니다. 웹(Vercel)으로 열었을 때는 이 기능을 쓰려고 하면 EXE 버전 안내 메시지가 뜨며, 그 외 회계 처리 기능은 모두 동일하게 사용할 수 있습니다.

## 라이선스

비영리 목적으로 자유롭게 사용·수정·배포할 수 있습니다.
